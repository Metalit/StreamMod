## Building

For a full introduction to Quest modding, visit the [BSMG Wiki](https://bsmg.wiki/modding/quest/intro.html).

In addition to the normal build steps, this project requires you to have a local C/C++ compiler in order to set up protobuf, not just the Android NDK. If on Windows, `MSYS2` is recommended.
